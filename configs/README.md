# Configs

Tuned post-processing configuration files, one per dataset. Generated by `postprocess/run_tuning_all.py`.

---

## Files

| File | Method | Key Parameters |
|------|--------|----------------|
| `cityscapes.json` | CleverLabel | delta=0.1, mu=1.0, overcorrection_threshold=0.5 |
| `kitti.json` | CleverLabel | delta=0.0, mu=1.0, overcorrection_threshold=0.0 |
| `pascalvoc.json` | Downweight | downweight_factor=0.5 |
| `coco.json` | Multi-config (per super-category) | Varies by category group |

---

## Common Parameters

| Parameter | Description | Default |
|-----------|-------------|---------|
| `method` | Post-processing method (`cleverlabel`, `downweight`, `identity`) | — |
| `alpha` | Dirichlet smoothing parameter | 0.5 |
| `epsilon` | Epsilon smoothing floor | 1e-10 |
| `seed` | Random seed for train/val split | 42 |
| `train_ratio` | Fraction used for tuning | 0.5 |
| `classes` | Ordered list of class names (including `cantsolve`) | — |
| `transition_matrix` | Estimated class confusion matrix (for CleverLabel) | — |
| `delta` | CleverLabel: blending strength | — |
| `mu` | CleverLabel: correction scaling | — |
| `overcorrection_threshold` | CleverLabel: prevent over-correction above this threshold | — |
| `downweight_factor` | Downweight method: factor to reduce proposed-class probability | — |

---

## COCO Multi-Config

The COCO config (`coco.json`) contains multiple sub-configs, one per COCO super-category (e.g., `accessory`, `animal`, `vehicle`). Each super-category may use a different method and parameters, tuned independently.

---

## How to Regenerate

```bash
python -m postprocess.run_tuning_all
```

This tunes all datasets and writes updated configs to `configs/`.
